# Master Screen Empty and Error States

Required empty messages:

- Master Usage Overview: "No master usage summary has been reported yet."
- Workspace Usage: "No workspace usage records found for the selected filters."
- AI Cost Usage: "No AI cost usage has been reported yet."
- Plan Utilization: "No plan utilization records are available yet."
- Audit Logs: no matching audit logs.

Errors should be inline, concise, and free of stack traces or provider/payment secrets.
